# cosmic-samples
cosmic samples for live-coding


The repo.json file in the repository communicates which n number and which sound bank each sample can be accessed from in Estuary. Instructions: My repository can be used through Estuary, which can be found at: https://estuary.mcmaster.ca/ In Solo Mode, type this command into the Estuary terminal: !reslist "https://nadialofaro.github.io/cosmic-samples/repo.json"
